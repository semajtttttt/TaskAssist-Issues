# TaskAssist Issues

Public issue tracker for **TaskAssist**. The source code lives in a separate private repository.

## Report a bug or request a feature

**Use the form: <https://issues.taylor-server.org>**

You don't need an account. After you submit, you get a link to your issue so you can follow its progress.

## Browse issues

See [all issues](https://git.taylor-server.org/jtaylor91/TaskAssist-Issues/issues) to check whether something has already been reported.
